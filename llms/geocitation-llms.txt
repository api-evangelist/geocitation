# GEOCitation

> White-label AEO/GEO (Answer Engine / Generative Engine Optimization) audit API for SEO agencies and SaaS platforms. A single asynchronous REST API that runs AI-visibility / citation-gap audits and returns structured JSON with citation probabilities, entity / semantic-cluster data, E-E-A-T scores, and content recommendations.

This llms.txt was generated by API Evangelist from the catalog record; the provider does not publish its own /llms.txt.

## API

- [GEOCitation Audit API](https://www.geocitation.io/en/documentation): Async REST API to launch Market-Intelligence and Gap-Analysis AEO/GEO audits, poll status, stream live events (SSE), and retrieve structured JSON + Markdown deliverables. Base URL https://api.geocitation.io/v1. Auth: X-API-Key header (keys prefixed geo_citation_); Bearer also accepted. Submit returns 202 + audit_id; completion typically 5-7 minutes; HMAC-SHA256 signed webhooks (audit.completed, audit.failed).
- [OpenAPI 3.1](https://api.geocitation.io/openapi.json): Machine-readable contract, 15 paths / 17 operations.
- [Interactive API reference (Swagger UI)](https://api.geocitation.io/docs)

## Key operations

- create_audit — POST /v1/audits (Market or Gap)
- list_audits — GET /v1/audits
- get_audit — GET /v1/audits/{audit_id}
- get_audit_status — GET /v1/audits/{audit_id}/status
- stream_audit — GET /v1/audits/{audit_id}/stream (SSE)
- get_document — GET /v1/audits/{audit_id}/documents/{doc_type}
- get_manifest — GET /v1/audits/{audit_id}/manifest
- read_usage — GET /v1/usage
- get_kpi_catalog — GET /v1/meta/kpi-catalog
